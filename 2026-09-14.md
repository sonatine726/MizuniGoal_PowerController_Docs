Hoffman-san, Marlon-san

I have looked into the matter raised during the meeting regarding the voltage and placement of the power status LED.

Given factors such as the low current flowing through the switch on the current PCB, using a "switch with an integrated LED" connected to the switch port is not ideal. While we could revise the PCB design if an integrated LED switch were required, the plan is to switch to an "emergency stop pushbutton." Therefore, from an overall optimization standpoint, it seems better to install the LED using the layout shown in the attached diagram.

Pros:
- Greater flexibility in LED selection (since a dedicated resistor can be used, virtually any LED is compatible).
- Greater flexibility in wiring (switch wiring and LED wiring are separate, allowing for individual optimization).
Cons:
- This approach cannot be used if an integrated LED switch is strictly required.

Please consider this option. It can be confusing to have two switches (an emergency stop pushbutton *and* a switch with an integrated LED); I may have misunderstood the situation, and the original plan might have been to use a separate LED rather than an integrated LED switch. If that is not the case and you absolutely require a switch with an integrated LED, please let me know so we can revise the PCB design.

*Note: In either scenario, the voltage applied to the LED will be the same as the battery voltage (approx. 21.0V to 29.4V).
*Note: Regarding the LED connection, branching the output line should be easy since splitter connectors for XT60s are commercially available. However, if this proves difficult, we could add a dedicated LED connector to the PCB. Please let me know if such a PCB modification is preferred.
